# Cane Bluetooth App

## Project Documentation

This project is aimed at providing a Bluetooth-enabled cane for the visually impaired. The cane allows users to navigate their environment with auditory feedback from connected devices.

### Features
- Bluetooth connectivity
- Obstacle detection
- Voice feedback
- Adjustable sensitivity settings

## Setup Instructions

To set up the Cane Bluetooth app on your local machine, follow these steps:

1. **Clone the Repository**:  
   Use the command below to clone the repository to your local machine.
   ```bash
   git clone https://github.com/crdi37225-lab/cane-bluetooth-app.git
   ```

2. **Navigate to the Directory**:  
   ```bash
   cd cane-bluetooth-app
   ```

3. **Install Dependencies**:  
   Make sure you have the correct dependencies installed. You can install them using:
   ```bash
   npm install
   ```

4. **Run the Application**:  
   After installing the dependencies, you can start the application using:
   ```bash
   npm start
   ```
